Gael utilizó Terraform de forma directa para levantar y organizar
infraestructura cloud dentro del proyecto empresarial para Banregio. No fue
solamente una revisión conceptual: trabajó con código de infraestructura,
módulos reutilizables, variables, outputs, redes, dependencias y configuración
por entorno.

Aplicó estándares y convenciones definidos para el entorno Banregio, cuidando
la modularidad, el etiquetado, la consistencia de nombres y la colaboración con
otros equipos. También validó despliegues y documentó decisiones para que la
infraestructura fuera comprensible y repetible.

El impacto cualitativo fue reducir configuración manual, mejorar la
reutilización y facilitar que los cambios de infraestructura pudieran revisarse
y reproducirse. No se atribuye una cifra de ahorro porque no existe una métrica
auditada disponible.
