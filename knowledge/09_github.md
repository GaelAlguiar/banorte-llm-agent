## Enfoque

El GitHub público complementa la experiencia empresarial. El repositorio de este agente será la evidencia principal de ingeniería GenAI. Autogestor-Carpetas demuestra automatización con Python y procesamiento basado en datos.

Otros repositorios muestran experiencia con APIs REST en TypeScript, autenticación mediante NextAuth, aplicaciones Flutter/Dart, consumo de datos financieros y desarrollo web. Algunos son proyectos de aprendizaje y se presentan como evidencia complementaria, no como sistemas empresariales en producción.

## Criterio de presentación

El valor del portafolio no está en afirmar dominio de todas las tecnologías. Está en mostrar continuidad: aplicaciones, datos, APIs, identidad, automatización, cloud y finalmente soluciones GenAI integradas y evaluadas.
