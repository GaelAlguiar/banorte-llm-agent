## Fortalezas principales

Python, FastAPI, APIs REST, OpenAI, RAG, embeddings, agentes con herramientas, evaluación básica, SQL Server, Firebase, Node.js, TypeScript, Flutter, Docker, Git y Terraform.

## Cloud e integración

Experiencia práctica con Azure, AWS y Google Cloud; APIM, AKS, Container Apps, Functions, redes, VPN, seguridad y despliegue de infraestructura.

## Java y microservicios

Cuenta con experiencia y fundamentos relacionados con Java y arquitectura de microservicios, especialmente contratos REST, separación de responsabilidades, integración, autenticación, despliegue y observabilidad. Java no sustituye su fortaleza principal en Python y TypeScript, pero amplía su capacidad para colaborar con ecosistemas empresariales heterogéneos.

## Frameworks de agentes

Su experiencia principal está en OpenAI y componentes propios. Los fundamentos implementados —prompts, tools, retrieval, estado, evaluación y guardrails— son transferibles a LangChain, Agents SDK, Google ADK y otros frameworks.

## Datos

Sus fundamentos de datos se apoyan en trabajo con SQL, fuentes operativas,
hojas de cálculo, APIs y datos no estructurados. Comprende la diferencia entre
una base transaccional, una fuente documental y un índice vectorial.
