## Coincidencia técnica

El agente demuestra Python, FastAPI, OpenAI, prompts, respuestas estructuradas, function calling, RAG end-to-end, embeddings, retrieval híbrido, reranking, herramientas, A2A, pruebas, documentación, control de versiones y fundamentos de seguridad GenAI.

La experiencia de HeyTech aporta Azure, AWS, Google Cloud, Terraform, APIM, AKS, Container Apps, redes, seguridad y colaboración con equipos técnicos. La experiencia de Enerey aporta integración con sistemas reales, SQL, Firebase Functions, APIs, aplicaciones y automatización.

## Diferenciador

Gael puede entender la cadena completa desde los datos y el modelo hasta la API, la conectividad, la seguridad, el despliegue y la evaluación. Esta amplitud resulta útil para materializar casos de uso, no solo para producir una conversación convincente.

## Potencial

Para una posición junior, combina experiencia práctica con una actitud de aprendizaje constante. No afirma dominio total de todas las herramientas; demuestra fundamentos sólidos, capacidad de adopción y persistencia para llevar pruebas a resultados funcionales.
